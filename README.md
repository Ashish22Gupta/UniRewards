# 🎯 UniRewards - Earn & Redeem Platform

> A modern, gamified rewards platform for university students to earn points, complete challenges, collect stickers, scratch cards, and redeem real-world rewards.

## 🌟 Overview

**UniRewards** is a comprehensive web platform designed to engage university students through gamification. Users can sign up, complete various challenges (surveys, social media tasks, referrals, etc.), earn points, and redeem them for exciting rewards like cashback, Amazon vouchers, electronics, and more.

### ✨ Key Features

- 🎮 **Gamified Challenges** - Multiple challenge types with varying difficulty levels
- 🎫 **Scratch Cards** - Interactive scratch-to-reveal cards (Bronze, Silver, Gold tiers)
- 🏆 **Sticker Collection** - Collect and showcase achievement stickers
- 💰 **Real Rewards** - Redeem points for cashback, vouchers, and physical gifts
- 📊 **Leaderboard** - Compete with other users and track top earners
- 🔐 **KYC Verification** - Secure document upload with drag-and-drop
- 📱 **Multi-Step Registration** - Smooth, guided signup with OTP verification
- 🎨 **Modern UI/UX** - Beautiful, responsive design with smooth animations
